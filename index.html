Selected Projects

Lilac Trio

[GitHub]

Meta-reinforcement learning codebase for tracking task non-stationarity.

More about this project

Lilac Trio is a meta-reinforcement learning codebase around task non-stationarity. It includes experiment paths for LILAC, RL2, Thompson sampling, and Bayes policies, with environments such as AntGoal, Cheetah velocity, MiniGolf, and MiniGolf with signals.

The repository contains training scripts, meta-test scripts, robustness evaluation utilities, checkpoint inspection tools, and plotting code for comparing learned policies across changing task distributions.

Multi-Armed Bandits

Online decision-making experiments for exploration-exploitation tradeoffs.

More about this project

Implemented epsilon-Greedy, UCB, and Thompson Sampling algorithms in Python with NumPy, Pandas, and Matplotlib. The project focused on comparing regret and reward behavior under both stationary and non-stationary settings.

I also explored how bandit-style decision-making can be applied to financial trading strategies, where the useful action distribution can shift over time.

Generative Attacks on LLMs

Deep generative modeling for adversarial prompt synthesis and LLM robustness.

More about this project

Used deep generative models to synthesize adversarial prompts that probe robustness and failure modes of large language models. The project studied how generated prompts behave under different safety filters and what kinds of mitigation strategies can improve robustness.

The work combined PyTorch, Hugging Face Transformers, and experiment-driven evaluation.

Seizure Prediction

EEG signal-processing project using spectral entropy and classical ML methods.

More about this project

Developed seizure-prediction experiments using spectral entropy features extracted from EEG signals. I evaluated KNN, SVM, regression methods, and artificial neural networks for neurological monitoring applications.

The project connected signal processing with practical machine-learning pipelines for biomedical data.

Hessian-Free Optimization

Conjugate-gradient methods for convex optimization from scratch.

More about this project

Implemented conjugate-gradient and Hessian-free optimization methods from scratch, targeting numerical accuracy and practical speedups over standard solver baselines.

The experiments reached optimality gaps at or below 1e-6 and were applied to portfolio optimization and sparse regression tasks.
